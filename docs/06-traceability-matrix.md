## Легенда статусов

| Статус | Значение |
|---|---|
| Покрыто | Есть требование, API и тест |
| В разработке | Требование есть, API/тест ещё не готовы |
| Не покрыто | Нужно добавить |

## Как поддерживать

1. Новое требование получает ID и владельца.
2. Добавляется use case или обновляется существующий.
3. Обновляется OpenAPI и, при необходимости, схема данных.
4. Добавляется UAT-сценарий.
5. Матрица обновляется в том же PR.
6. На релизе проверяются все P0-строки.
