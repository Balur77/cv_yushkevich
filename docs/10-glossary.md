# Глоссарий

> Единый язык проекта. Обезличенные определения, без внутренних кодов банка.

| Термин | Определение |
|---|---|
| **АБС** | Автоматизированная банковская система: учёт договоров, счетов, проводок и остатков. |
| **Acceptance criteria** | Проверяемые условия, при которых требование считается выполненным. |
| **AS-IS** | Описание текущего процесса «как есть». |
| **TO-BE** | Описание целевого процесса «как должно быть». |
| **BPMN 2.0** | Нотация моделирования бизнес-процессов: дорожки, задачи, шлюзы, события. |
| **UML** | Язык моделирования: use case, sequence, activity, state machine, class. |
| **ERD** | Модель сущностей и связей базы данных. |
| **DFD** | Диаграмма потоков данных. |
| **Use case** | Сценарий взаимодействия актора с системой для достижения цели. |
| **User story** | Короткое описание потребности от лица пользователя. |
| **Guard-условие** | Условие, при котором переход статуса или операция разрешены. |
| **Traceability matrix** | Матрица связи требований, дизайна, API и тестов. |
| **DoR** | Definition of Ready: требование готово к разработке. |
| **DoD** | Definition of Done: решение готово к передаче. |
| **Идемпотентность** | Свойство операции давать один и тот же результат при повторе. |
| **Idempotency-Key** | Ключ, по которому сервер распознаёт повтор команды. |
| **Retry** | Повторная попытка выполнения операции после ошибки. |
| **Backoff** | Увеличение интервала между повторными попытками. |
| **Timeout** | Максимальное время ожидания ответа. |
| **Circuit breaker** | Предохранитель, который временно блокирует вызовы неисправного сервиса. |
| **Компенсация** | Обратное действие для отмены частично выполненной операции. |
| **Сверка (reconciliation)** | Сравнение данных между системами для выявления расхождений. |
| **Mapping** | Правила преобразования данных из источника в приёмник. |
| **Problem Details** | Стандартный формат описания ошибок HTTP API (RFC 7807). |
| **OpenAPI** | Спецификация описания REST API. |
| **Swagger** | Инструменты вокруг OpenAPI: редактор, UI, генерация. |
| **Postman** | Инструмент ручной проверки и коллекций API. |
| **UAT** | User Acceptance Testing: приёмочное тестирование бизнесом. |
| **Smoke test** | Быстрая проверка базовой работоспособности. |
| **Регресс** | Повторная проверка после изменений. |
| **SLA** | Соглашение об уровне сервиса. |
| **MTTR** | Среднее время восстановления после инцидента. |
| **RPS** | Запросов в секунду. |
| **p95** | 95-й перцентиль времени ответа. |
| **ПДн** | Персональные данные. |
| **NDA** | Соглашение о неразглашении. |
| **MVP** | Минимально жизнеспособный продукт. |
| **Change request / ЗНИ** | Запрос на изменение с оценкой влияния. |
| **Runbook** | Инструкция для поддержки по диагностике и восстановлению. |
| **Hypercare** | Усиленная поддержка сразу после релиза. |
